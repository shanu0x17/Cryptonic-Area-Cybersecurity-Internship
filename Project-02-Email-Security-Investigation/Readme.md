# 📧 Project 02 — Email Security Investigation

## Overview

This project documents a structured investigation of a suspicious email. The objective was to analyze email artifacts, identify indicators of compromise (IOCs), assess potential threats, and document findings using an incident response approach.

The investigation was conducted in an educational environment for learning and documentation purposes.

---

## Objectives

- Analyze suspicious email content
- Identify Indicators of Compromise (IOCs)
- Assess phishing indicators
- Document investigative findings
- Produce a professional investigation report

---

## Investigation Workflow

- Evidence Collection
- Email Header Analysis
- IOC Identification
- Threat Assessment
- Findings Documentation
- Reporting

---

## Tools Used

- Email Header Analyzer
- Browser Developer Tools
- Online Security Resources

---

## Deliverables

- Professional Email Security Investigation Report (PDF)

---

## Skills Demonstrated

- Email Analysis
- Incident Investigation
- IOC Analysis
- Security Documentation
- Technical Reporting

The investigation was performed solely for educational purposes using authorized training material.
